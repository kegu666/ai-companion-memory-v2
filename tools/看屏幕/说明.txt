让她看见你的屏幕 · 使用说明
================================

这是一个独立的小工具：每隔几秒截一次屏，认出屏幕上的字，
写成 ocr.json。别的程序读这个文件，就能"看见"你在干什么。


【它不会】看到图像
---------------
没有视觉模型，没有多模态。它只认字。

所以：
  ✓ "屏幕上写了什么"        → 答得准
  ✗ "我在干什么"            → 只能靠文字猜
  ✗ "这个界面长什么样"      → 完全不知道


【怎么用】三步
---------------
1. 双击 安装.bat      等它装完（下模型要几分钟）
2. 双击 启动.bat      会开一个黑窗口，最小化它
3. 看 ocr.json        每次识别会刷新这个文件

要停：关掉那个黑窗口，或者按 Ctrl+C。


【产物长什么样】
---------------
ocr.json：
{
  "t": 1761499200.12,
  "lines": [
    "第 1 行文字",
    "第 2 行文字",
    "..."
  ]
}

latest.jpg 是刚才截的那张图（调试用）。


【怎么接进自己的 bot】
---------------
见 接进你的bot.md。核心就一句：
读 ocr.json，把 lines 拼成一段话，塞进提示词。


【三个坑】
---------------
1. 全屏文字全塞会吃掉几千 token
   本脚本已经限制到 60 行 / 1600 字。
   想改就改 screen_ocr.py 开头的 MAX_LINES / MAX_CHARS。

2. 认字会错
   "小鲸鱼" 可能认成 "小辣鱼"。
   这不影响理解大意，但别指望逐字准确。

3. OCR 比截图慢
   截图 0.1 秒，认字要 5~8 秒。
   所以实际是每 8~10 秒一次，不是 2 秒。
   想快就调小 MAX_LINES，认的字少了就快。


【要求】
---------------
- Windows 10 / 11
- Python 3.10 以上
- 第一次装依赖要联网（约 100 MB）
- 不需要 ffmpeg（截屏用 Pillow 自带的 ImageGrab）
